# Upstream provenance

The `rockbox/` directory is a source snapshot of [Rockbox](https://github.com/Rockbox/rockbox)
at commit [`59f15ca63079f0bd735d0b02d686257bd7b5205b`](https://github.com/Rockbox/rockbox/commit/59f15ca63079f0bd735d0b02d686257bd7b5205b),
plus the Shanling M3X port changes present in this development workspace.
The upstream Git history is available at that repository; it is not duplicated
in this workspace-shaped repository.

Existing file headers, copyright notices and component licenses are preserved.
See `rockbox/docs/COPYING`, `rockbox/docs/LICENSES`, `rockbox/docs/COPYING-MANUAL`
and individual component notices for their terms. The root `LICENSE` reproduces
Rockbox's GNU GPL version 2 text. The test MP3 has its own Creative Commons
Attribution 3.0 license and credits in `media/Sneaky_Snitch_credits.txt`.

Proprietary firmware and boot images, device dumps, local SDKs/toolchains,
compiled programs and personal development logs are not distributed here.
