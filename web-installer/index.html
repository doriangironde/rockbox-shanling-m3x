Install Rockbox

Install or update Rockbox on your Shanling M3X.

Experimental: browser installation is not hardware-tested. Back up your music and settings first. Prefer the tested command-line installer if unsure.

1. Prepare your player

  • Shanling M3X only, firmware 1.75 / Android 7.1.1.
  • Magisk root and the GPIO18/19 audio fix already installed.
  • Battery at least 50%. Return to Android and stop Rockbox.
  • Enable USB debugging. Use desktop Chrome or Edge and a data-capable USB cable.

Not rooted? This page cannot install root yet. Do not re-root a working player.

2. Connect your player

Plug the M3X directly into your computer. Click Connect M3X and select it. On the player, allow USB debugging and Magisk root access when prompted.

No player connected.

Ready. Connect your player to start.

3. Select and verify the installer

Download the installer ZIP from the release attachments, not “Source code”. Select it below, then click Verify installer.

The ZIP and player are checked before installation. Files stay local.

4. Install Rockbox

Confirm your backup, then click Install Rockbox. Keep this tab open and the USB cable connected until completion.

Updates keep music and settings and create a rollback snapshot. No firmware is flashed.

5. Open Rockbox

  • Wait for “completed”. Save the backup path from the operation log for rollback.
  • Open Rockbox in Android. Start at low volume.
  • Choose Return to Android in Rockbox to exit. Android remains the default boot.
  • Disconnect, revoke USB-debugging access and disable debugging when finished.

Run only trusted plugins and Lua scripts; root access is not a sandbox.

Connection help
  • Use Chrome or Edge over HTTPS or localhost. Safari and Firefox cannot connect over USB.
  • Stop desktop ADB if it owns the USB connection. Avoid hubs and virtual machines.
  • Linux may need USB permissions; Windows may need a compatible driver. Do not replace drivers blindly.
  • Reloading or disconnecting forgets the browser key; authorize the player again.

If connection fails, use the command-line installer. Browser/OS driver compatibility is not yet validated on the M3X.

Restore a snapshot

Connect your rooted player, enter the snapshot name saved from the log, then click Restore Rockbox snapshot.

This restores old settings, loader and security limits. It does not restore firmware.

Developer tools: root preparation & EDL — experimental

Boot-partition writes are disabled. Browser flashing and recovery are not hardware-validated.

A failed boot flash can prevent booting or lose data. Rooting weakens Android security. A boot backup does not include music or settings; keep a separate data backup and a working native recovery setup.

Prepare a root image

For development on an unrooted M3X only. M3X fastboot cannot flash, boot or reboot: do not use OEM-unlock, factory-reset or generic fastboot recipes.

Select your stock firmware 1.75 boot.img, the official Magisk 30.7 APK and the verified MSM8937 programmer. These files are not supplied or uploaded.

Prepared images and this patching method are untested on an unrooted player. Saving an image does not install root or prove it will boot.

Connect EDL and back up boot

Rebooting enters Qualcomm EDL, not fastboot. Re-authorize USB for 05c6:9008. Connect only this M3X; have recovery files ready before rebooting.

Read-only diagnostics

Already rooted? Select the programmer above and use this path instead. It runs the programmer in RAM and reads boot, without partition writes or flash authorization.

Save and verify your backup

Save both the full 64 MiB boot backup and recovery JSON. Keep the JSON private: it contains device identity. Reopen the saved backup below and verify it.

Device identity, programmer and disk layout are checked. Root installation also requires stock 1.75 boot; diagnostics can back up an already-rooted boot image.

Boot flash and restore — disabled

EDL entry without a booting Android system is not validated. adb reboot edl cannot recover a player that no longer boots Android.

Only boot can be written; full readback must match. No erase, unlock, other partition writes or automatic reboot. Never disconnect, close the tab or power off during a write.
